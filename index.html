Methodology

What each mode means

Product task flow

The recommended mode. It tests whether a shopper can identify the product, evaluate title, reviews and price, select an option, then reach the primary action. This is a task model, not a universal eye pattern.

Grouping & crowding

Related elements should form a readable cluster without overlap. Nearby irrelevant objects and occlusion reduce identification. Complete or partial covering is penalized directly.

Gutenberg diagram

A historical layout heuristic that divides a page into primary optical, strong fallow, weak fallow and terminal areas. It is included as an optional exploratory lens, not presented as a biological law or precise prediction.

Gaze cueing

The direction of an observed face can shift attention toward the gazed-at side. The model provides only a small directional adjustment and never overrides visibility or task completion.
